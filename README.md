# Kaggle - Predicting Heart Disease

This repository contains my solution for the Kaggle Playground Series - Season 6, Episode 2: [Predicting Heart Disease](https://www.kaggle.com/competitions/playground-series-s6e2).

## 📊 Overview
The goal of this competition is to predict the presence of heart disease in patients based on various clinical features such as age, blood pressure, and cholesterol levels. 
As a Master's student specialized in signal processing and data analysis, I aim to apply robust machine learning techniques to achieve high prediction accuracy.

## 🛠️ Repository Structure
- `notebooks/`: Google Colab notebooks for EDA and model training.
- `src/`: Reusable Python modules for data preprocessing and configuration.
- `data/`: (Local only) Competition datasets (excluded from Git tracking).

## 🚀 Goals
- Achieve a high ROC-AUC score on the leaderboard.
- Implement a clean, modular code structure (following PEP 8).
- Practice professional data science workflows using Git and Google Colab.

## 🔧 Tech Stack
- **Python** (Pandas, NumPy, Scikit-learn, XGBoost/LightGBM)
- **Google Colab** (Computation environment)
- **Git/GitHub** (Version control)
